# TASTY — Restaurant Website Demo

A responsive restaurant website concept built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize before showing a client
- Replace the TASTY demo name and all sample copy.
- Replace sample dishes and prices with client-approved details.
- Replace emoji artwork with photos the client owns or has permission to use.
- Add the client's real phone, address, opening hours, and official messaging link.
- Test all links and the mobile layout.

## Publish
Create a GitHub repository, upload these files, then enable GitHub Pages in the repository's Settings → Pages. The site is static HTML/CSS/JS; it does not include a backend, database, payment processing, or real order management.

**Important:** This is a fictional portfolio demo, not a real restaurant. Do not present it as paid work for an actual business.
